## 高斯核函数

高斯核函数（Gaussian Kernel Function），也叫**径向基核函数（RBF Kernel，Radial Basis Function Kernel）**，是机器学习中最常用的一种核函数，尤其适用于支持向量机（SVM）等算法。

### 数学定义

高斯核函数的表达式为：

\[
K(\mathbf{x}, \mathbf{x}') = \exp\left( -\frac{\|\mathbf{x} - \mathbf{x}'\|^2}{2\sigma^2} \right)
\]

或等价形式（常用 \(\gamma\) 参数）：

\[
K(\mathbf{x}, \mathbf{x}') = \exp\left( -\gamma \|\mathbf{x} - \mathbf{x}'\|^2 \right)
\]

其中：

- \(\mathbf{x}, \mathbf{x}'\)：两个输入样本向量
- \(\|\mathbf{x} - \mathbf{x}'\|^2\)：两个向量的**欧氏距离平方**
- \(\sigma\)：**带宽参数**，控制核的"宽度"
- \(\gamma = \frac{1}{2\sigma^2}\)：另一种常见的参数化方式

### 直观理解

- 当两个样本点距离很近时（\(\|\mathbf{x} - \mathbf{x}'\| \approx 0\)），核函数值接近 **1**，表示两者非常相似。
- 当两个样本点距离很远时，核函数值趋近于 **0**，表示两者几乎不相似。
- 因此高斯核本质上是一个**相似度度量函数**，将原始空间中的点映射到无限维特征空间。

### 核心特性

| 特性 | 说明 |
|------|------|
| **正定性** | 高斯核是正定核，满足 Mercer 条件 |
| **局部性** | 只有距离近的点对核函数值有显著影响，远处的影响迅速衰减 |
| **无限维映射** | 对应一个无限维的特征空间 |
| **平滑性** | 生成的决策边界平滑，不易过拟合（参数合适时） |

### 参数作用

- **\(\sigma\) 较大（\(\gamma\) 较小）**：核函数更"宽"，影响范围更大，决策边界更平滑 → 偏向欠拟合
- **\(\sigma\) 较小（\(\gamma\) 较大）**：核函数更"尖"，只关注极近的点，决策边界更复杂 → 偏向过拟合

### 常见应用场景

1. **支持向量机（SVM）**—— 处理非线性分类/回归问题
2. **高斯过程（Gaussian Processes）**—— 作为协方差函数
3. **核主成分分析（Kernel PCA）**—— 非线性降维
4. **核密度估计（KDE）**—— 概率密度估计

### 为什么常用

高斯核是机器学习中的"默认选择"核函数，因为它只有一个参数需要调优，且能处理大多数非线性问题，不需要像多项式核那样担心阶数选择，也不需要像 Sigmoid 核那样担心参数敏感度。
